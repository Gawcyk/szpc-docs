# ŚlZPC — dokumentacja i podgląd aplikacji

Publiczna dokumentacja systemu internetowego **Śląskiego Związku Podnoszenia Ciężarów (ŚlZPC)**:
serwisu informacyjnego (aktualności, kalendarz zawodów, kluby, „O związku”) oraz paneli do prowadzenia
ewidencji związku.

Kod źródłowy jest rozwijany w osobnym, prywatnym repozytorium. To repozytorium zawiera wyłącznie
wybrane, publiczne materiały kopiowane jednostronnie — zmiany zgłoszone tutaj nie są przenoszone do kodu.

## Zawartość

- [Podgląd strony](PODGLAD-STRONY.md) — zrzuty ekranu części publicznej i panelu administratora
  (desktop i telefon).

## Dane na zrzutach

Wszystkie zrzuty wykonano automatycznie na odizolowanej bazie z **fikcyjnymi danymi demonstracyjnymi**.
Osoby, kluby, licencje, adresy i wydarzenia na zrzutach nie pochodzą z rzeczywistej ewidencji związku.

## Technologie

Laravel · PHP · React · TypeScript · Inertia.js · Tailwind CSS · SQLite.

## Znaki i grafiki

Logo ŚlZPC oraz banery widoczne na zrzutach należą do Śląskiego Związku Podnoszenia Ciężarów lub ich
autorów. Zrzuty służą wyłącznie prezentacji aplikacji; znaki i grafiki nie są udostępniane na otwartej
licencji.
